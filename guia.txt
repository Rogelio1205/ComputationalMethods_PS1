GUÍA RÁPIDA PARA USAR CLOJURE EN VS CODE

1. Crear una carpeta nueva para cada tarea
Ejemplo:
Tarea01
Tarea02
PracticaFunciones

2. Abrir la carpeta en VS Code
File → Open Folder → seleccionar la carpeta de la tarea

3. Crear archivo principal de Clojure
Ejemplo:
tarea01.clj

4. Crear archivo deps.edn
Dentro de la misma carpeta crear un archivo llamado:
deps.edn

Pegar esto dentro:

{:paths ["."]
 :deps {org.clojure/clojure {:mvn/version "1.12.5"}}}

Guardar con Ctrl + S.

5. Escribir código en el archivo .clj
Ejemplo:

(println "Hola Clojure")

(+ 2 3)

6. Iniciar Clojure con Calva
Presionar:
Ctrl + Shift + P

Buscar:
Calva: Start a Project REPL and Connect

o también puede salir como:
Calva: Jack-in

Elegir:
deps.edn
o
Clojure CLI

7. Esperar a que diga “Jack-in done”
Eso significa que ya está listo.

8. Ejecutar código
Poner el cursor en la línea que quiero probar y presionar:
Ctrl + Enter

Ejemplo:
(+ 2 3)

Debe salir:
5

9. Para otra tarea
Cerrar esa carpeta o abrir otra:
File → Open Folder

Crear otra carpeta nueva y repetir los pasos.

NOTA:
Las carpetas .calva, .clj-kondo, .cpcache, .lsp y el archivo .nrepl-port los crea VS Code/Calva automáticamente. No pasa nada, no son error.
